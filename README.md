# Зачётка — помощник студента

Веб-приложение (PWA), которое устанавливается на телефон: расписание, аудитории, задания и подготовка презентаций.

- **Сегодня** — текущая и следующая пара, аудитория, ссылка на вебинар, ближайшие дедлайны.
- **Расписание** — по неделям и датам, импорт `.ics` из личного кабинета вуза.
- **Аудитории** — маршрут на день и все аудитории.
- **Задания** — рефераты, лабораторные, курсовые с шагами и сроками.
- **Презентация** — план слайдов по времени и таймер репетиции.

Данные хранятся только в браузере телефона (localStorage). Сборка не нужна: это статические файлы.

## Установка на телефон
1. Опубликуйте репозиторий через GitHub Pages (Settings → Pages → ветка, папка `/`).
2. Откройте ссылку в Chrome (Android) или Safari (iPhone).
3. Меню → «Добавить на главный экран».
